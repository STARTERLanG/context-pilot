## 硬性红线

- 禁止硬编码密钥/密码/Token。
- 禁止日志中输出密码、Token、身份证号、银行卡号。
- 禁止 SQL 拼接（必须使用参数化查询或 ORM）。
- 禁止用户输入未经校验直接用于文件路径或 HTML 渲染。
- 禁止裸 `except:` 捕获异常。
- `.env` 文件禁止提交 Git。

## 输入校验

- 文件上传使用白名单校验扩展名。
- 路径操作使用 `Path.resolve()` + 前缀校验，防止路径遍历。

## OWASP 防御要点

| 威胁         | 防御                       |
| ------------ | -------------------------- |
| SQL 注入     | ORM 参数化查询             |
| XSS          | 输出编码 + CSP             |
| CSRF         | SameSite Cookie + Token    |
| 敏感数据泄露 | 脱敏日志 + HTTPS           |
| 依赖漏洞     | `uv lock --check` 定期扫描 |
